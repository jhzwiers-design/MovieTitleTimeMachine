# Movie Title Time Machine

Web page for my Motion Design 2 opening title sequence for *Earth vs. the Flying Saucers* (1956).
It shows the final title sequence, two process cuts (Review 7 and Review 8), and how the slides were made.

Live at: https://jhzwiers-design.github.io/MovieTitleTimeMachine/

## Files
- `index.html` — the page
- `video/final.mp4` — final, color-corrected title sequence (1080p)
- `video/cut01.mp4` — Review 7, Cut 01 (720p)
- `video/review8.mp4` — Review 8, stabilized with sound (720p)
- `images/` — poster frames, stills and process photos

Every file is under 25 MB, so the folder can be uploaded through github.com in the browser.
